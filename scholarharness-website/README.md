## 授权码配置

注册页支持月度、季度、年度三档本地客户端授权说明，统一引导用户扫码加入内测群联系获取软件授权码/内测码，不直接展示公开购买链接。

后台管理页的“内测码”标签中有“链动小铺卡密导出”模块，可按套餐生成授权码并下载 TXT。TXT 为一行一个授权码，可直接导入卡密池。用户拿到授权码后填入注册页的“授权码/内测码”即可激活对应天数的软件使用权限。
