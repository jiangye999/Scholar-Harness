## ✅ 填写步骤

### Step 1: 确定运营主体

根据您的实际情况填写：
- **个人运营**：填写个人姓名和居住地址
- **公司运营**：填写公司名称和工商注册地址
- **高校团队**：填写团队名称和学校地址

### Step 2: 填写联系方式

- **客服邮箱**：已固定为 `sjs@cau.edu.cn`（如需更改请全局替换）
- **客服电话**：建议填写座机或专用手机号
- **负责人信息**：填写实际负责人姓名和联系方式

### Step 3: 确定价格方案

根据 `configs/models.json` 和实际运营策略填写订阅价格。

参考 `cloud/database/schema.sql` 中的默认配置：
- 季度订阅：99元（schema.sql 行522）
- 年度订阅：299元（schema.sql 行523）
- 激活码：199元（schema.sql 行524）

### Step 4: 确认第三方服务商

根据实际使用的服务商填写：
- AI服务商：查看用户配置的默认 API providers
- 支付服务商：微信支付、支付宝
- 存储服务商：根据部署配置确定

### 使用 sed 批量替换（Windows PowerShell）

```powershell
# 示例：替换公司名称
(Get-Content "docs/legal/01-privacy-policy.md") -replace '\[请补充公司/个人名称\]', '中国农业大学农业气象研究团队' | Set-Content "docs/legal/01-privacy-policy.md"
```

## ⚠️ 重要提醒

1. **法律审核**：填写完成后，建议聘请专业律师审核所有文档
2. **备案准备**：部分地区可能要求向网信办备案，保留文档原件
3. **版本管理**：填写后更新文档版本号和生效日期
4. **用户通知**：重大变更需通知现有用户
