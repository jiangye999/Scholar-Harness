# 对话流程设计

## 概述

ScholarClaw 使用状态机驱动的对话流程，引导用户完成学术论文写作。

## 对话阶段

### 1. greeting (问候)

**触发条件**: 用户首次对话或发送"你好"/"开始"

**AI 行为**:
```
你好！我是学术论文写作助手 🎓

我可以帮助你完成学术论文的写作，包括：
• 根据你的研究内容生成论文
• 按照目标期刊的风格要求
• 智能引用相关文献
• 生成 LaTeX 格式的文档

请告诉我你的论文主题是什么？
```

**状态转移**: → topic

---

### 2. topic (主题)

**触发条件**: 用户回复主题

**AI 行为**:
```
很好！主题是：[用户主题]

接下来请问：
1. 你的目标期刊是哪个？
2. 或者你更关注某个具体的研究领域？
3. 如果没有特定期刊，我可以帮你推荐合适的期刊
```

**状态转移**: → journal

---

### 3. journal (期刊)

**触发条件**: 用户指定期刊

**AI 行为**:
```
收到！你希望发表在 [期刊名]

现在我需要一些材料来开始写作：

📄 必需：
   - 你的研究内容（Word 文档，包含实验设计、结果等）

📄 推荐：
   - 目标期刊的范文 PDF（1-3 篇）
   - 文献数据库（Web of Science 导出）

请先上传你的研究内容文档。
```

**状态转移**: → upload

---

### 4. upload (上传材料)

**触发条件**: 用户上传文件或粘贴内容

**AI 行为**:
```
收到你的研究内容！让我分析一下...

[分析进度]

✅ 分析完成！

你的研究内容包含：
- [主要发现/结论]
- [实验方法]
- [数据/图表]

接下来我们可以开始规划论文了。
```

**状态转移**: → planning

---

### 5. planning (章节规划)

**触发条件**: 材料分析完成

**AI 行为**:
循环询问每个章节的写作重点：

```
📝 引言 (Introduction)
请描述你引言的写作重点：
例如：研究背景、已有研究、研究问题、你的创新点

请用 1-2 句话描述。
```

用户回答后继续下一个章节。

**章节顺序**: introduction → methods → results → discussion → abstract → conclusion

**状态转移**: → writing (所有章节规划完成)

---

### 6. writing (写作执行)

**触发条件**: 用户确认章节规划

**AI 行为**:
```
好的！准备开始写作。

我将按照以下流程：
1. 一级 AI 生成详细的写作 skill
2. 二级 AI 根据 skill 写作
3. 一级 AI 进行质量检查

开始写作引言部分...
```

每个章节写作时：
```
📝 引言章节写作中...
   ✓ 正在生成写作 skill
   ✓ 正在撰写内容
   ✓ 正在添加文献引用
   ✓ 正在进行质量检查

引言完成！字数：850 字
```

**状态转移**: → complete (所有章节完成)

---

### 7. complete (完成)

**触发条件**: 所有章节写作完成

**AI 行为**:
```
🎉 恭喜！论文写作完成！

📄 生成的章节：
   ✓ 摘要 (Abstract) - 280 字
   ✓ 引言 (Introduction) - 850 字
   ✓ 方法 (Methods) - 1200 字
   ✓ 结果 (Results) - 1500 字
   ✓ 讨论 (Discussion) - 1100 字
   ✓ 结论 (Conclusion) - 350 字

📁 输出文件位置：output/sections/
```

---

## 状态转移图

```
greeting → topic → journal → upload → planning → writing → complete
   ↑           ↓        ↓         ↓          ↓          ↓
   └───────────┴────────┴─────────┴──────────┴──────────┘ (重置)
```

## 特殊处理

### 中断和恢复
- 用户可以随时说"保存"保存进度
- 说"继续"从上次位置继续
- 说"重置"重新开始

### 修改规划
- 在 planning 阶段可以说"修改引言"重新规划
- 在 writing 阶段可以说"重新写引言"

### 错误处理
- 上传失败：提示替代方案（粘贴文本）
- API 错误：自动重试 + 提示用户
- 内容分析失败：请求用户补充信息
