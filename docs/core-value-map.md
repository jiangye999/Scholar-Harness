# Scholar Harness 核心价值地图

> 用户购买的不是“AI 写出来的一段话”，而是更快、更稳地完成科研任务，并把过程沉淀为以后仍然可用的研究资产。

## 1. 价值单位

SH 的最小价值单位不是消息、Token 或文档，而是一个 **可追溯科研交付任务**：

- 有明确科研目标；
- 调用了正确的项目资料和专业工具；
- 形成文稿、数据、图表、报告或审计结果；
- 结论能够回到文献、证据句、数据或操作记录；
- 用户可以继续修改、复用、分享或导出。

## 2. 用户真正购买的结果

1. **缩短科研周期**：减少找资料、清洗数据、切换工具、重复排错和格式整理的时间。
2. **降低错误与返工**：减少错误引用、证据不匹配、分析步骤遗漏和文件版本混乱。
3. **提高成果质量**：让写作、统计、图表和论证受到期刊规则与质量门禁约束。
4. **降低专业工具门槛**：用自然语言驱动 R、Python、Office、检索和科研工作流。
5. **积累研究资产**：把一次性聊天变成可检索、可验证、可复用的个人或团队知识资产。
6. **获得过程可控性**：知道 AI 用了什么、做了什么、为什么得出结论，以及失败后如何恢复。

## 3. 核心价值链

| 用户痛点 | SH 能力 | 用户价值 | 商业价值 |
|---|---|---|---|
| 文献散落在 PDF、RIS、文件夹和网站 | 统一文献模型、PDF 管理、Embedding 文献库 | 快速找到可用资料 | 形成长期留存的项目资产入口 |
| AI 引用看似正确但无法核验 | PDF Wiki 句子级证据、引用映射、支撑度检查 | 降低错引和学术风险 | 构成高信任、高付费意愿的差异化能力 |
| 每次写作都要重新解释项目 | 项目上下文、长期记忆、草稿与分析结果联动 | 连续工作，减少重复输入 | 提升留存和迁移成本，但不依赖数据锁定 |
| 搜索结果太多且不够相关 | BM25 候选粗筛、向量检索、reranker、元数据过滤 | 更快得到可用证据 | 节省模型成本并提高结果质量 |
| 研究工具多、流程割裂 | Agent 执行内核、R/Python/Office/MCP 工具 | 用一个任务串起多个工具 | 支撑 Pro 自动化和 Lab 标准工作流收费 |

| 实验室经验依赖少数人 | 共享 Skill、模板、证据库、权限和审计 | 降低带教成本，保留组织知识 | Lab/Enterprise 的核心付费理由 |
| 模型快速变化，担心被单一厂商锁定 | 多模型、BYOK、本地优先、插件接口 | 成本和隐私可控 | 降低平台替代风险并扩大渠道 |
| 需要定制但外包改造昂贵 | 构造 Agent、能力地图、审批与回滚 | 可控地扩展本地软件 | 高级用户增购、企业定制和生态增长 |

## 4. 四层价值架构

### 第一层：即时效率

- 快速阅读、搜索、总结、写作和修改；
- 自动处理文档、表格、图像和代码；
- 减少在多个软件之间复制粘贴。

这一层最容易被大模型厂商复制，只适合获客，不能作为唯一壁垒。

### 第二层：可信交付

- 结论与证据一一对应；
- 引用、数据和操作可审计；
- 任务有质量门禁、失败恢复和最终产物。

这是个人 Pro 的核心付费层。

### 第三层：研究资产复用

- 文献、句子证据、数据、方法、图表和草稿形成项目资产图谱；
- 旧项目的有效证据和工作流可在新任务中按权限复用；
- 每次使用都会提高下次任务的速度和一致性。

这是留存和实验室价值的核心。

### 第四层：组织治理

- 团队知识库、成员权限、模板治理、审计、成本与模型策略；
- 私有部署、SSO、数据区域、合规和 SLA；
- 机构级科研 Agent 和内部系统连接。

这是 Lab 和 Enterprise 的高客单价值层。

## 5. Research Asset Graph：最重要的产品资产

建议把当前分散的数据结构收敛为 **Research Asset Graph（研究资产图谱）**：

```text
Research Question
  ├─ Literature / PDF
  │    ├─ Evidence Sentence
  │    ├─ Reference
  │    └─ Extraction Provenance
  ├─ Dataset / Analysis / Figure
  ├─ Claim / Paragraph / Draft
  ├─ Skill / Workflow / Tool Run
  └─ Review / Decision / Audit Log
```

图谱必须记录来源、版本、权限和生成过程，而不只是节点连线。它带来三种复利：

- 检索复利：项目越完整，后续检索越准确；
- 工作流复利：成功步骤可以固化为模板和 Skill；
- 质量复利：真实接受/退回结果可以改进评估与路由。

用户原始数据始终属于用户。SH 可保护的是图谱引擎、质量评分、匿名聚合评估和工作流优化方法，而不是占有用户数据。

## 6. 各版本应交付的结果

| 版本 | 用户购买的主要结果 | 不应成为主要卖点 |
|---|---|---|
| Free | 能开始一个真实项目，并得到一次可信的小闭环 | 无限聊天、堆砌功能 |
| Pro | 个人复杂科研任务能稳定完成，证据和资产持续复用 | 单纯更高 Token 额度 |
| Lab | 团队资料、规范和 Agent 工作流可共享、可治理 | 只做多人账号折扣 |
| Enterprise | 在机构安全边界内规模化使用科研 Agent | 只做一个私有化安装包 |

## 7. 价值衡量体系

### 北极星指标

**每周被用户接受的可追溯科研交付任务数。**

### 领先指标

- 首个项目从创建到首个有效产物的时间；
- 任务完成率、恢复成功率、人工接管率；
- 有明确证据来源的事实性句子比例；
- 检索结果被采用率，而非仅点击率；
- 项目资产在后续任务中的复用率；
- 用户修订后保留的 AI 内容比例；
- Pro 激活率、Lab 席位扩张率和月度留存。

### 反指标

- 不把消息数、生成字数、工具调用数视为价值；
- 不用“用户上传了多少数据”代替活跃度；
- 不以模型消耗增长作为成功；
- 不奖励无来源的快速输出。

## 8. 价值主张文案

面向个人：

> 把你的文献、数据和科研工具组织成一个会持续工作的研究助理；从证据到文稿，每一步都能追溯。

面向实验室：

> 把实验室的文献、方法、模板和科研经验沉淀为团队可复用、可治理的 Agent 工作流。

面向机构：

> 在机构的数据与合规边界内，部署可审计、可扩展、模型无关的科研 AI 基础设施。
