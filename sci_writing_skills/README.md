# SCI Writing Skills Pack

This package contains AI-guiding markdown skills for major SCI paper sections:

1. 01_title_skill.md
2. 02_abstract_skill.md
3. 03_introduction_skill.md
4. 04_methods_skill.md
5. 05_results_skill.md
6. 06_figures_tables_skill.md
7. 07_discussion_skill.md
8. 08_conclusion_skill.md
9. 09_additional_statements_skill.md

Design principles:
- each file is directly usable as an AI writing instruction
- each file includes purpose, inputs, workflow, checklist, and prompt template
- structure follows the uploaded Scientific Manuscript Writing Guide
