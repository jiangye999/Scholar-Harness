# OpenScience Academic Skill Pack

This package contains a curated subset of skills extracted from
`synthetic-sciences/openscience` at commit
`ef3d6e74538feec022c0db429a87df5001ec8fb5`.

The original relative directory structure is preserved so each `SKILL.md` can
refer to its companion `references/`, `scripts/`, `assets/`, and examples.

Scholar Harness loads these files lazily. Loading a skill does not execute its
scripts and does not grant additional filesystem, network, or shell permission.
Application safety rules, user instructions, verified evidence, and target
journal requirements take precedence over conflicting skill text.

See `LICENSE`, `NOTICE`, and skill-local license files before redistribution.
