# 架构影响分析

按“入口 → 前端状态 → API → 服务 → 数据 → 恢复 → 展示”追踪完整链路。

- 优先复用首页内嵌页面、统一聊天内核、现有 API 与数据目录。
- 识别字段名、路径和错误模型是否与现有契约一致。
- 若需求触碰认证、支付、更新器、Electron 主进程、云数据库迁移或 app.asar，停止运行时安装，转为正式版本变更建议。
- 对功能包给出最小贡献面：页面、导航、命令、私有存储和 HTTPS 网络权限。
- 标明刷新、重启、历史恢复和窄屏时的预期行为。

输出影响矩阵和推荐边界，不直接跳到代码。
