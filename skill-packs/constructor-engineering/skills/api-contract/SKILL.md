# 前后端 API 契约

- 所有外部输入先做 schema 校验和长度限制。
- 成功响应返回 `success: true` 与明确数据对象。
- 失败响应返回 `code`、`message`、`recoverable`，不返回堆栈或密钥。
- 长任务使用持久化 job id；页面重开后可继续读取状态和日志。
- 读操作幂等；启用、禁用、安装和回滚允许安全重试。
- 路径值只允许功能包范围内的相对路径，服务端再次解析验证。

先写契约再写界面，字段变更必须同时检查调用方和测试。
