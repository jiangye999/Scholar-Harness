# 迁移与回滚

- 新版本安装到独立版本目录，不覆盖上一版本。
- 切换 activeVersion 前完成清单和资源校验。
- 数据结构变化使用向前迁移并保留原始副本；不得静默破坏旧数据。
- 回滚只切换代码版本，默认保留功能私有数据。
- “删除功能”先停用，再卸载代码；清理用户数据必须单独确认。
- 记录安装时间、版本序列、当前版本和最后状态变化。

完成条件：升级失败可恢复到上一可用版本，重启后注册表和页面状态一致。
