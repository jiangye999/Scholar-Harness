# 测试与启用门禁

按顺序检查：

1. `feature.json` schema、版本和贡献引用。
2. 所有资源存在且未越过包目录。
3. HTML/JS 语法、CSP 与 sandbox 兼容性。
4. API 成功、失败、空数据和重复提交。
5. 页面刷新、软件重启、历史状态恢复和禁用后清理。
6. 窄屏、长文字、键盘操作和错误提示。
7. 旧版本回滚可用且用户数据不丢失。

任何阻断项失败都保持功能包停用。报告必须给出失败位置和修复建议。
